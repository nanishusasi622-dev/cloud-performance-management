# ☁️ Cloud Performance Management

## 📌 Project Overview

**Cloud Performance Management** is a Python-based simulation project that monitors and analyzes the performance of cloud resources.

The system monitors important performance metrics such as:

* CPU Usage
* Memory Usage
* Response Time

Based on these metrics, the system identifies the cloud performance status as **Normal, Monitor, or Warning**.

The project also generates graphs to visualize resource utilization and response time.

---

## 🎯 Objectives

* Monitor cloud resource performance.
* Analyze CPU and memory utilization.
* Measure simulated response time.
* Detect high resource usage.
